# Favala Hardware Chatbot — Reduced 6-Part Rig

This website-animation pack groups the approved chatbot into six practical assemblies:

1. Head with helmet and headset
2. Body with vest, belt, wrench and screwdriver
3. Complete open-hand arm
4. Complete thumbs-up arm
5. Neck joint
6. Floating base

Both transparent PNG and self-contained SVG versions are included. The SVG files embed the approved 3D raster artwork; they are not vector-path redraws. Use `rig-manifest.json` for suggested CSS transform origins and layer order.
